Data Dictionary

DATASET OVERVIEW

This dataset is being developed for the independent research project:

When Claims Become Facts: Testing Epistemic-Status Distortion in AI-Assisted Dark-Web Threat Intelligence.

The dataset records original cyber-threat claims supplied to Large Language Models (LLMs), the experimental conditions under which they are processed, and the resulting model-generated outputs.

The purpose is to examine whether AI-generated responses preserve or alter the evidentiary status of explicitly unverified threat claims.

Dataset Status: In Development
Research Type: Controlled Experimental Study

 VARIABLE DEFINITIONS

claim_id

A unique identifier used to distinguish individual claims.

Example: C001, C002, C003.

condition

Identifies the experimental condition assigned to the input claim.

The exact condition labels will be defined in the experimental methodology.

input_claim

Contains the original threat-related statement provided to the model.

Claims will retain their original uncertainty labels so that changes in evidentiary status can be evaluated.

output_text

Contains the model-generated response without changing its original wording.

Outputs will be preserved for subsequent evaluation.

DATA HANDLING

Original input claims and generated outputs will be preserved separately.

Outputs will not be manually rewritten before evaluation.

Each claim will be assigned a unique identifier.

Experimental conditions will be recorded consistently.

Missing or incomplete outputs will be documented.

API keys, credentials and other sensitive information will not be included in the dataset.

DATA LIMITATIONS

The dataset is intended for controlled research rather than operational threat intelligence.

The results may be influenced by model versions, prompt design, sampling settings and the characteristics of the selected claims.

The dataset and its documentation will be updated as the experimental study progresses.
